# 📱 AppTecOn

Aplicativo desenvolvido em **React Native** com foco no aprendizado prático da tecnologia.

---

## 🎯 Objetivo

Entender a estrutura e funcionamento do **React Native**, criando uma tela de **Login** e uma tela **Home**, com componentes reutilizáveis e estilizados.  
Este projeto foi um desafio pessoal para explorar uma nova linguagem e ambiente de desenvolvimento mobile.

---

## 🧩 Tecnologias utilizadas

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- [Expo Router](https://expo.github.io/router/)
- [@expo/vector-icons](https://docs.expo.dev/guides/icons/)

---

## 🧱 Componentes

- **Header**: com ícone de casa, título da página e botão de menu.
- **Profile**: exibe o nome do usuário e empresa.
- **Calendar**: botão/ícone representando ações com o calendário.

## 🚀 Como rodar o projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/apptecon.git
   cd apptecon

2. Instale as dependências:
   ```bash
   npm install
   
3. Inicie o app:
   ```bash
   npx expo start

4. Escaneie o QR Code com o aplicativo Expo Go no seu dispositivo.

📌 Observações
O projeto está estruturado com expo-router, utilizando rotas baseadas em arquivos.

O layout foi ajustado com SafeAreaView e StatusBar para melhor compatibilidade com diferentes dispositivos.
